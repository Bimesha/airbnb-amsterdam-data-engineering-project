# AI Usage Disclosure

AI tools were used as support during this project. They were used to help understand the assessment requirements, organize the work and improve documentation.

## AI Tools Used

- ChatGPT

## Areas Where AI Assisted

- Understanding the assessment brief and required deliverables.
- Breaking the assignment into manageable sections.
- Planning the project folder structure and report structure.
- Understanding how each part of the project output maps to the assessment sections.
- Improving the wording of README and report sections.
- Explaining how to document assumptions, limitations, and decisions.
- Improving the clarity of business interpretations and recommendations.

## Example Prompt Types Used

- "Explain the assessment requirements in simple terms."
- "Help me organize the final project folder structure."
- "Help me write this report section professionally."
- "Help me explain the limitations and assumptions clearly."
